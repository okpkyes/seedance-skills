# 真人三视图全身像（角色定档底图）

> 整合自 `ai-realperson-threeview-prompt` skill。seedance 已有 §15 影楼面部三联图（灰幕布 A/B/C，仅面部），本文件补充**全身三视图 + 左侧 50% 面部特写、纯白背景**的定档底图版式——作为所有人物向作品（图生图、视频、换装、角色卡、短剧定妆）的统一输入素材（turnaround sheet）。

## 版式规范（固定，不可省略）

```
┌─────────────────────────────────────────────┐
│  [ 左侧 50% ]        │   [ 右侧 50% ]        │
│   正面面部特写大图     │   ↑ 正面全身          │
│   (占画面50%，精细)   │   → 侧面全身          │
│                       │   ↑ 背面全身          │
│                       │  (三视图上下排列)     │
└─────────────────────────────────────────────┘
```

- **左侧 50%**：一张正面精细的**面部特写大图**，占画面 50%，皮肤纹理是第一优先级。
- **右侧 50%**：三视图全身像（正面 / 侧面 / 背面），站立不动，分别从三个角度观察全身。
- 用细竖线将左侧特写与右侧三视图分隔开，线条笔直、间距均匀，呈现干净版式。
- 人物**站立不动、自然站立、面无表情**，纯白背景。
- 人物身份、面部比例、发型、服装、身材比例在四个区域**完全匹配**（角色一致性锚定）。

> 与 §15 影楼三联图的区别：本版式是**纯白背景 + 全身三视图 + 面部特写**，而非灰幕布面部三联；仅借用其"身份/比例完全匹配、面板分隔"的纪律。

## 下游视频（以底图为 @图片1 锚定）

- **角色数字锁**：参考 `@图片1` 的人物形象与服装，不重写容貌，根除特征漂移。
- **微动态优先**：缓慢转身 → 略微侧头 → 发丝轻拂；避免狂奔 / 大跳 / 剧烈打斗（物理穿模）。
- **约束安全网**：无字幕、无 Logo/水印；面部绝对稳定不变形；无物理穿模。
- **时长分段**：≤15s 单段；>15s 用分段 + 视频延长（上段作 `@视频1`）。
